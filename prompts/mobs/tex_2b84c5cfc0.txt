# Ragdoll Cat — Creature Reference

Create a high-quality visual material reference for the entity/variant described below. This reference will be used in a second pass to transfer appearance onto an already structurally correct UV atlas; do not create a UV map, texture atlas, Minecraft render, voxel model, diagram, or game screenshot.

SUBJECT:
A Ragdoll-inspired colorpoint cat: pale cream body with cooler gray-brown points on face, ears, legs and tail, soft transitions and plush fur. Preserve clear point coloration and avoid Siamese-level starkness.

ART DIRECTION:
Grounded dark-fantasy realism: ancient, weathered, somber, tactile and physically believable. Use restrained saturation, soft neutral diffuse lighting, controlled micro-detail and natural material transitions. Preserve the recognizable source identity and variant; do not redesign anatomy, add accessories, exaggerate horror, cute-ify the subject, or turn it into a different species.

REFERENCE FUNCTION:
Make pigmentation, markings, surface materials, age/wear and color relationships easy to read across the important visible body/material regions. Prefer a clear neutral three-quarter presentation or similarly informative view over dramatic action. Avoid heavy shadows, colored cinematic lighting, strong depth of field, glossy toy surfaces, cartoon/anime styling, pixel art, text, UI and decorative scene clutter.

Use a simple neutral unobtrusive background. The image should be useful primarily as a clean appearance/material reference for later UV transfer.
